## Prerequisites

- Go 1.23.5
- Node.js 22.12 or newer and pnpm 11.11.0
- PostgreSQL 17
- `just` 1.40.0
- Docker with Compose for the production-shaped path

## GitLab setup

Create an OAuth application whose redirect URI exactly matches `SITCON_BOARD_GITLAB_OAUTH_REDIRECT_URL` and enable its `api` scope. User OAuth tokens execute Work Item GraphQL mutations and read or write issue Comments so GitLab permissions and actor attribution remain intact. Provide a project access token able to read members, labels, and Work Items in `sitcon-tw/2027` for snapshots, the Label catalog, and webhook reconciliation.

Production realtime delivery also requires a Project webhook for **Work item events** and a Premium/Ultimate Group webhook for **Member events**. Generate independent Signing tokens in GitLab, leave the legacy Secret token empty, and configure the matching `SITCON_BOARD_GITLAB_PROJECT_WEBHOOK_SIGNING_TOKEN` and `SITCON_BOARD_GITLAB_GROUP_WEBHOOK_SIGNING_TOKEN` values. The complete field-by-field setup is in the Dokploy runbook.

The directory file must exist at `.sitcon/board-directory.yml`. Each team can list GitLab usernames under `leaders`; the bulk-create mode creates one matching card per configured team and assigns all of that team's leaders. The Docker build copies the file into the image, so changing it requires a new build and deployment, not a GitHub API token.

## Run from source

```bash
pnpm install
cp server/.env.example .env
# Set SITCON_BOARD_DATABASE_URL and GitLab credentials in .env.
just backend-migrate-up
```

Use separate terminals:

```bash
just backend-dev
```

```bash
just web-dev
```

The web server at `http://localhost:5173` proxies `/api` to the backend at `http://localhost:8080`.

For isolated browser design checks, run `VITE_SITCON_DEMO=true just web-dev`. This explicitly loads a test-only fixture and must not be used as a production data source.

Delta sync is enabled by default. During the staged rollout, build the web app with `VITE_SITCON_SYNC_DELTA=false` to restore the legacy bootstrap revision stream and five-second full polling as a temporary kill switch.

## Production-shaped stack

```bash
cp deployments/docker/example.env deployments/docker/.env
# Replace every change-me and add GitLab OAuth, project access, and webhook credentials.
docker compose --env-file deployments/docker/.env -f deployments/docker/compose.yaml up --build
```

Open `http://localhost:3000`. Compose waits for PostgreSQL, completes migrations, then starts the application. Readiness remains false until the first directory/member/board sync succeeds.

## Validate

```bash
just ci
```

PostgreSQL integration tests use `SITCON_BOARD_TEST_DATABASE_URL` and remain a separate infrastructure-backed command: `just backend-test-integration`.
