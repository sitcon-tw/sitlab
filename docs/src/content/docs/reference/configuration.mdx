Configuration uses the `SITCON_BOARD_` prefix and is validated before the HTTP server accepts traffic.

The GitLab project is deliberately fixed to `sitcon-tw/2027`. Board access requires an active GitLab `Planner` role or higher. Background reads use the project Reporter / `read_api` token; mutations use the requesting user's OAuth `api` token so GitLab preserves the real actor. Authenticated GitLab requests are origin checked, redirects are refused, and the client only constructs the fixed-project REST and GraphQL operations plus the `/user` identity lookup. The OAuth scope itself remains account-wide, so raw-token theft is a residual risk even though the application request boundary is project-fixed.

Cipher keyring entries are comma-separated `key-id:unpadded-base64url-encoded-32-byte-key` values. The first entry encrypts new data; later entries decrypt old envelopes for lazy rotation. State and user-token keyrings must be different. Keep prior token keys until the OAuth revocation queue is empty and all live credentials have rotated.

## Session invariant

Session lifetime is fixed in code at 14 days and is not a runtime setting. Every valid authenticated use updates `last_used_at`, moves `expires_at` to 14 days from now, and returns a renewed HttpOnly cookie. Expired sessions are rejected and deleted.

In production, the controller refuses development or malformed keyrings, reused state/token keyrings, missing GitLab credentials, malformed webhook signing tokens, an insecure/non-`__Host-` cookie, malformed URLs, short keys, empty database configuration, or invalid sync intervals. Signing tokens must use GitLab's `whsec_` format and encode independent 32-byte keys.

Logout revokes the user's OAuth grant after their last active browser session closes. Expired sessions, membership loss, role downgrade below Planner, and replacement sign-in also place the old access/refresh pair into a durable revocation queue. Operators should alert on a growing `gitlab_oauth_revocation_queue_tokens` or `gitlab_oauth_revocation_oldest_age_seconds` metric.
